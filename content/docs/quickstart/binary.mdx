## Start Parseable

Install the binary and start Parseable in local-store mode:

```sh
curl -fsSL https://logg.ing/install | bash
parseable local-store
```

On Windows, use the installation script in PowerShell:

```powershell
powershell -c "irm https://logg.ing/install-windows | iex"
```

The local instance listens on port `8000`. Open [the Parseable console](http://localhost:8000) and sign in with the default credentials, `admin:admin`.

## Verify and continue

When the console loads, follow the [quickstart](/get-started) to send one event to the `demo` dataset and confirm it appears in the log explorer. For production deployment options, see [self-hosted installation](/self-hosted/installation).
