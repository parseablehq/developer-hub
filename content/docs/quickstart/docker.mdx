## Start Parseable

Install [Docker](https://www.docker.com/products/docker-desktop/) if it is not already available, then run:

```sh
docker run -p 8000:8000 \
  -p 8001:8001 \
  -p 8002:8002 \
  -v /tmp/parseable/data:/parseable/data \
  -v /tmp/parseable/staging:/parseable/staging \
  -e P_FS_DIR=/parseable/data \
  -e P_STAGING_DIR=/parseable/staging \
  quay.io/parseablehq/parseable:latest \
  parseable local-store
```

The container listens on port `8000`. Open [the Parseable console](http://localhost:8000) and sign in with the default credentials, `admin:admin`.

## Verify and continue

When the console loads, follow the [quickstart](/get-started) to send one event to the `demo` dataset and confirm it appears in the log explorer. For production deployment options, see [self-hosted installation](/self-hosted/installation).
