Follow one of these guides to start an instance. For a local binary or Docker instance, continue below to send your first event. For Cloud, use the ingestion endpoint and credentials shown in your workspace instead of the local values.

## Send your first event

The local instance listens on port `8000`. Send one JSON event to the `demo` dataset:

```bash
curl --location 'http://localhost:8000/api/v1/ingest' \
  --header 'X-P-Stream: demo' \
  --header 'Authorization: Basic YWRtaW46YWRtaW4=' \
  --header 'Content-Type: application/json' \
  --data '[{"message":"hello from Parseable"}]'
```

The `X-P-Stream` header selects the dataset. The authorization header uses the local default `admin:admin` credentials.

## Verify it worked

Open [the local console](http://localhost:8000), sign in with `admin` / `admin`, and select `demo` in the log explorer. You should see the event with `message` set to `hello from Parseable`.

If it does not appear, confirm that Parseable is still running, then check the URL, credentials, and `X-P-Stream` header in the command above. For a production deployment, use the [self-hosted installation guide](/self-hosted/installation).
