Start asynchronous deletion of an existing dataset. After deletion state is established, the request returns HTTP 202 with `log stream {name} deletion started`.

Object-storage cleanup runs as a deduplicated background task. If cleanup is interrupted, it is discovered and resumed after restart. Repeating the DELETE request while cleanup is active returns HTTP 202 with `log stream {name} deletion already in progress`.

While deletion is in progress:

- The dataset is excluded from dataset listings.
- Reads, ingestion, retention operations, hot-tier operations, and statistics access are blocked.
- The dataset cannot be recreated.
- Creating or updating the dataset returns HTTP 409 with `Logstream {name} is being deleted, please retry shortly`.
- Ingestion that reaches the dataset after deletion begins returns HTTP 409 with `Dataset {name} is being deleted`.

When deletion finishes, all associated data has been permanently removed.
